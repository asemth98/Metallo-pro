# MetalloPro — منصة تعليم هندسة المواد والمعادن

تطبيق ويب تفاعلي بلا خادم (Vanilla JS + HTML5 Canvas). 

## هيكل المستودع

```
# MetalloPro

منصة تعليمية تفاعلية لهندسة المواد والمعادن مبنية بالكامل باستخدام Vanilla JavaScript و HTML5 Canvas دون الحاجة لأي خادم خلفي (Serverless).

## هيكل المشروع

تم تنظيم المشروع في مجلدات واضحة لسهولة التعديل والصيانة:

```text
metallo-pro/
├── index.html          # نقطة الدخول الرئيسية وترتيب تحميل السكربتات
├── css/
│   ├── base.css        # التنسيقات الأساسية
│   ├── duo.css         # تنسيقات مسار التعلم (Duolingo-style)
│   └── v6.css          # تنسيقات الإصدار السادس (الثيم النهاري، الشاشة الكاملة...)
└── js/
    ├── core/           # الأساسيات (الحالة العامة، محرك الرسم، إدارة الوحدات)
    ├── data/           # الدروس والبطاقات والبيانات الثابتة
    ├── duo/            # محرك مسار التعلم والمراجعة الذكية
    ├── labs/           # شفرات المختبرات مقسمة حسب الأقسام الأكاديمية
    ├── registry/       # فهرس وتوصيف الوحدات التدريبية
    └── v6/             # طبقة الإضافات البرمجية (v6) ومختبر TTT/CCT الجديد

تطبيق ويب تفاعلي بلا خادم (Vanilla JS + HTML5 Canvas).

## ترتيب التحميل مهم

الملفات تحمل عبر `<script>` بالترتيب المكتوب في `index.html`، ولا توجد وحدات ES. كل ملف يعتمد على ما قبله:

1. `core/` أولاً لأنه يعرّف `ST` و`REG` و`mod()` و`prep()`.
2. `data/` و`duo/` ثم `labs/` لأن init functions يجب أن تكون معرّفة قبل تسجيلها.
3. `registry/` بعد المختبرات لأنه ينفّذ استدعاءات `mod(...)` التي تشير إلى تلك الدوال.
4. `core/shell.js` ثم ملفات `v6/` التي تغلّف `selectMod` و`setMode` و`axes`.
5. `v6/99-boot.js` آخر ملف، ويعمل بعد `DOMContentLoaded` القديمة.

**لا تغيّر ترتيب `registry/` داخل `index.html`**، لأن الترقيم في القائمة يعتمد على ترتيب التسجيل.

## أين أعدّل ماذا؟

| أريد أن... | الملف |
|---|---|
| تغيير لون أو خط | `css/base.css` أو `css/v6.css` (وفي الوضع النهاري `body.theme-light`) |
| تعديل معادلة أو رسم مختبر معيّن | الملف الخاص بقسمه في `js/labs/` |
| تعديل نص شرح المرشد لمختبر | `mod(...)` الخاص به في `js/registry/` |
| إضافة مصطلح للموسوعة | `DICT` في `js/labs/VI-encyclopedia.js` |
| تعديل دروس المسار | `js/data/duo-units.js` أو `lessons-extra.js` |
| تعديل التقرير المطبوع | `buildReport` في `js/v6/05-export.js` |
| تعديل نموذج TTT/CCT | `js/v6/m35-ttt.js` (المعادلات موثّقة في رأس الملف) |
| إضافة زر أو عنصر للهيدر | `index.html` داخل `<header class="app-header">` |

## إضافة مختبر جديد

1. أضف دالة `initXX(root)` تبني HTML داخل `root` وتُرجع دالة `draw`، في ملف القسم المناسب داخل `js/labs/`.
2. أضف استدعاء `mod('mXX', cat, 'الاسم العربي', 'English name', 'icon', tutorObject, initXX);` في آخر ملف داخل `js/registry/`.
3. أضف اسم الملف الجديد إلى `index.html` إذا أنشأت ملفاً جديداً.

الترقيم والقائمة والشريط السفلي والعدادات تتحدّث تلقائياً من `REG`.

## ملاحظات

- نموذج TTT/CCT في `m35-ttt.js` تعليمي ومبسّط ومعايَر تقريبياً. ليس بديلاً عن بيانات مادة معتمدة.
- حالة الرابط العميق تُخزَّن في الهاش (`#m35&ttR=40`)، فيمكن مشاركة تجربة كاملة برابط واحد.
- بيانات التقدم في `localStorage` للمتصفح الحالي فقط، واستخدم زر التصدير في الفهرس للنقل بين الأجهزة.

## الملف المستقل (الأسهل للرفع)

`MetalloPro_v6_single.html` ملف واحد يحتوي الموقع كاملاً (CSS وJS مدمجان داخله) ولا يحتاج أي ملف آخر.
إذا رفعت المستودع على GitHub ولم تظهر المجلدات كاملة، ارفع هذا الملف وحده وسيعمل.

بعد أي تعديل على ملفات `js/` أو `css/` أعد بناء الملف المستقل بالأمر:

```
python3 scripts/build.py
```
